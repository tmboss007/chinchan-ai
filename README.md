**Chinchan Core** is a cyberpunk-themed, high-performance AI assistant built with Streamlit. It features a highly customized UI, dynamic motion graphics, and the ability to seamlessly switch between ultra-fast open-source models via Groq and Google's Gemini 2.0.

🔴 **[Try the Live App Here](https://chinchan-core-ai.streamlit.app)** 🔴

---

## ✨ Features

*   **Dual AI Engine:** Switch instantly between Groq (Llama-3) for blazing-fast responses and Google Gemini.
*   **Personality Modes:** Talk to Chinchan in different personas—Shinchan, Professional, Creative, or Coder.
*   **Cyberpunk UI:** Custom CSS featuring animated scanlines, neon gradient text, floating chat bubbles, and glowing UI elements.
*   **Session Analytics:** Real-time tracking of message counts and word generation in the sidebar.
*   **Export Chat:** Download your entire conversation history as a formatted Markdown file.
*   **Resilient API Handling:** Built-in rate limit detection and exponential backoff.
